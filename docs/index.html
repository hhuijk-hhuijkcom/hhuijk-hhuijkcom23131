FAQ

常见问题

入库后的游戏怎么启动？

像普通游戏一样在 Steam 库中点击「开始」即可，同样支持 Steam 的快捷界面与截图功能。请遵守 Steam 订阅协议，不建议对非本人拥有的游戏使用。

会修改我原有游戏的数据吗？

不会。入库只操作 Steam 库配置与快捷方式信息，不影响原有游戏文件、存档与成就数据。

杀毒软件提示怎么办？

部分杀毒软件可能误报，可加入信任列表或从源码自行构建。

「GitHub 生成」模式需要什么？

需要在设置中配置 GitHub Token，入库将通过云端工作流完成；不配置则可用「本地生成」离线模式。
