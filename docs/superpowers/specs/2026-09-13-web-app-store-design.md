# Web App Store 设计文档

- 日期：2026-09-13
- 仓库：hhuijk-hhuijkcom/hhuijk1312（main 分支）
- 状态：已获用户批准

## 1. 背景与目标

构建一个 **App Store 式网页应用商城**，用于展示和分发网页应用 / 工具程序。

目标：
- 访问者浏览、搜索、查看工具应用详情、收藏感兴趣的条目
- 维护者可仅通过修改 JSON 数据文件来上架新应用，无需改代码
- 纯静态前端，零构建、零依赖，可部署到任意静态托管平台

上线形态：现代极简风（参考 iOS App Store 视觉语言：毛玻璃、圆角卡片、柔和阴影）。

## 2. 非目标 / 边界

- 不实现用户注册登录、支付、评论等后端能力
- 不实现任何下载业务逻辑；"获取"仅提供外链跳转（应用部署地址），由数据字段控制
- 不编写任何绕过软件授权、破解相关内容的功能实现；示例数据使用通用工具/效率类应用

## 3. 需求规格

| 编号 | 需求 | 说明 |
|------|------|------|
| F1 | 应用列表首页 | 精选 Banner 轮播、精选横滑卡片、热门榜单、分类 Tab |
| F2 | 分类筛选与搜索 | 按分类过滤；关键字实时搜索（名称/标签/描述）；搜索历史 |
| F3 | 应用详情页 | 图标、名称、评分、分类、版本、描述、截图区、标签、相关推荐 |
| F4 | 收藏功能 | localStorage 持久化；收藏页查看与移除；导航栏红点计数 |
| F5 | 空状态处理 | 搜索无结果、收藏为空、详情 id 不存在时给出友好提示 |
| F6 | 响应式 | 移动端适配，卡片网格按视口宽度自适应（2-4 列） |

## 4. 架构方案

选型：**原生单页应用（SPA）+ JSON 数据**（方案 A，用户已确认）。

- 单一 `index.html` 作为唯一入口
- `hash` 路由实现视图切换（`#/`、`#/search`、`#/app/:id`、`#/favorites`），无页面刷新
- 无任何第三方依赖，无需构建步骤
- PWA manifest.json 提供可安装增强（可选）

### 4.1 文件结构

```
hhuijk1312/
├── index.html          # 唯一入口（头部导航 + 视图容器 + 模板）
├── css/style.css       # 全部样式（极简风、毛玻璃、卡片、响应式）
├── js/
│   ├── data.js         # 应用数据（约 12 个示例应用）
│   ├── store.js        # 状态管理：收藏、搜索历史（localStorage 封装）
│   ├── router.js       # hash 路由解析与分发
│   └── app.js          # 视图渲染、筛选排序、收藏交互、事件绑定
├── manifest.json       # PWA 元数据
└── README.md           # 项目说明 + 上架新应用的步骤
```

### 4.2 视图划分

| 路由 | 视图 | 内容 |
|------|------|------|
| `#/` | home | Banner 轮播 + 精选横滑 + 热门榜单 + 全部分类 Tab + 应用网格 |
| `#/search` | search | 顶部搜索框（实时联想）+ 分类筛选 + 结果网格 + 最近搜索 |
| `#/app/:id` | detail | 大图标/评分/描述/截图 + 获取与收藏操作 + 相关推荐 |
| `#/favorites` | favorites | 收藏应用网格 + 移除交互 + 空状态 |

## 5. 数据模型

`js/data.js` 暴露全局 `APP_DATA`：

```js
{
  id: "string",            // 唯一标识；详情页路由 id
  name: "string",          // 应用名
  icon: "string",          // Emoji 或 SVG/图片 URL
  category: "string",      // 属于 CATEGORIES 之一：工具|效率|娱乐|设计|教育|社交
  badge: "featured|new|hot|none",
  description: "string",   // 长描述（详情页展示）
  short: "string",         // 一句话简介（卡片展示）
  rating: 4.5,             // 0-5，一位小数
  installs: 12000,         // 安装/热度数，用于榜单排序
  version: "1.2.0",
  url: "https://...",      // "获取"按钮跳转目标
  screenshots: ["...", ...], // 截图 URL 或渐变色占位
  tags: ["效率", "云端"],    // 参与搜索匹配
  featured: false          // 是否进入精选
}
```

分类常量 `CATEGORIES = ["全部", "工具", "效率", "娱乐", "设计", "教育", "社交"]`。

## 6. 状态与数据流

- 应用数据：静态数组，纯前端内存态；视图渲染时按 `category / badge / rating / installs` 过滤与排序
- 收藏表：`localStorage` 键 `ws.favorites`，值为 id 数组；`store.js` 提供 `addFavorite / removeFavorite / isFavorite / getFavorites` 与变更事件通知
- 搜索历史：`localStorage` 键 `ws.history`，最多保留 8 条
- 路由：`window.addEventListener('hashchange')` 解析 hash 并调用对应视图渲染函数；渲染统一由 `render()` 进根容器，路由切换即重渲染

## 7. 视觉与交互要点

- 顶部导航：sticky + `backdrop-filter: blur` 毛玻璃；含首页/搜索/收藏入口 + 收藏红点
- 卡片：圆角 16px、轻阴影、hover 上浮；大图标用 Emoji 占位（可替换为图片）
- Banner：自动轮播 + 指示点，可点击跳详情
- 搜索：输入防抖 200ms 实时过滤，展示最近搜索 chips
- 收藏按钮：心形图标切换动画 + Toast 轻提示（"已收藏 / 已取消收藏"）
- 网格：`repeat(auto-fill, minmax(240px, 1fr))`，桌面 4 列、平板 3 列、手机 2 列

## 8. 测试与验证

- 本地验证：`python3 -m http.server 8000` 起服
- 用例清单：
  1. 首页四个区块正确渲染，Banner 可轮播
  2. 分类 Tab 切换过滤正确
  3. 搜索关键字实时过滤；无结果出现空状态
  4. 详情页路由往返（首页→详情→返回）状态保持
  5. 收藏/取消收藏持久化（刷新后仍在），导航红点计数正确
  6. 直接访问非法 id 显示"应用未找到"
  7. 移动端宽度下网格与导航正常

## 9. 上架新应用（维护者视角）

1. 复制 `js/data.js` 中任一对象，替换字段
2. 使用唯一 `id`，把 `url` 指向应用部署地址
3. 保存刷新即可预览；如需强制同步可 `ctrl+shift+r`
